AI Text to Video Generator

An AI-powered text-to-video synthesis system that converts natural language descriptions into dynamic, high-quality video sequences in real time.

Built the core generation pipeline with Python, PyTorch, and AnimateDiff-Lightning via Hugging Face Diffusers for fast GPU video rendering, integrated motion LoRA adapters and CLIP safety validation, then wrapped the model in a Gradio web interface.

  • PyTorch
  • Diffusers
  • Gradio
